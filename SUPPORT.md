# Getting Help and Support

[Türkçe](#türkçe)

## Where to ask

| I want to... | Go here |
|---|---|
| Learn how to use Harness Studio | The [user guide](docs/guide/en/README.md) and the [README](README.md) |
| Fix a problem | The [troubleshooting guide](docs/guide/en/10-troubleshooting.md), then search [existing issues](https://github.com/struklabs/harness-studio/issues) |
| Ask a question or share an idea | [GitHub Discussions](https://github.com/struklabs/harness-studio/discussions) |
| Report a bug or request a feature | [GitHub Issues](https://github.com/struklabs/harness-studio/issues/new/choose) |
| Report a security problem | [SECURITY.md](SECURITY.md) (private; never in public issues) |
| Contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

When you report a bug, include your operating system, GPU and driver, backend (CUDA, ROCm, Vulkan, Metal, CPU), Harness Studio version, the model you used, and the error text or an exported diagnostics report (see the troubleshooting guide) with personal information removed.

Harness Studio is maintained by volunteers; replies may take a few days.
