# Benchmark: Harness Studio vs llama.cpp run directly, on NVIDIA CUDA 4 GB (2026-10-15)

Generated by `bench/compare/summarize.py` from the raw JSON of the run (not committed: only this summary is in the repository). All numbers are medians of the stated number of runs on one machine; see Methodology and Caveats at the end.

## Reading notes

- Harness Studio ran headless (`harness serve --gateway`, release CLI from main 623e87c) on a separate data directory. The llama.cpp rows start the same `llama-server.exe` (b11574, CUDA) that Harness manages, directly, so every difference between the two is a product-level choice (context, layers, KV type, slots, admission), not an engine difference.
- Ollama and LM Studio were not part of this run.
- The "14b" slot holds Qwen3-0.6B Q8_0 because a 14B model does not fit a 4 GB card; the section titles below keep the runner's slot names.
- Card ceiling from `llama-bench` (same build, same files, all layers on the GPU, 3 repetitions):
